# コレクト | グッズ管理

Flet で作ったブラウザ用のグッズ管理アプリです。

## 主な機能

- 所持グッズを絞り込み、商品名・作品名から Google ショッピングでグッズを検索
- 端末に保存した写真を選択してグッズと一緒に保存し、所持画像との完全一致を確認
- 商品ページURLを登録し、所持品や検索結果から商品ページを直接開く
- バーコードを入力して Open Food Facts の公開データで商品を照合
- グッズを選択して登録し、購入済み・購入予定の状態や購入済み個数、購入金額、メモを管理
- 発売日、イベント、受取予定などのスケジュールを管理
- 複数の貯金目標と進捗を管理

グッズ登録では商品名・商品ページURL・購入状況・購入金額が必須です。購入済みの場合は購入個数も必須です。画像、作品名・ブランド、バーコード、メモは任意です。

## 使用技術と担当

| 技術・サービス | 関係する部分 |
| --- | --- |
| Python | 商品・予定・貯金目標の管理、検索、データ保存などのアプリ処理 |
| Flet | 画面表示と操作。ブラウザで使う Web アプリとして起動 |
| ブラウザ | 商品情報やバーコードの入力、画像のアップロード、アプリの表示 |
| Google ショッピング | 商品名・作品名からグッズを検索 |
| Open Food Facts API | バーコードから公開商品情報を照合 |
| Google 検索 / Google Lens | 商品名や選択画像を使った外部検索 |
| JSON・ローカルファイル | 登録データを `~/.goods_organizer.json`、画像を `~/.goods_organizer_images/` に保存 |

センサーや IoT 機器、クラウドストレージは使用していません。登録データと画像は実行した端末内に保存されます。Google ショッピングや Open Food Facts で商品情報を検索する場合はインターネット接続が必要です。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。
