# コレクト | グッズ管理

Flet で作ったブラウザ用のグッズ管理アプリです。

## 主な機能

- 商品名・作品名・所持グッズを検索
- 写真をアップロードして所持画像との完全一致を確認
- バーコードを入力して Open Food Facts の公開データで商品を照合
- 所持グッズ、購入金額、メモ、所持状態を登録・削除
- 発売日、イベント、受取予定などのスケジュールを管理
- 複数の貯金目標と進捗を管理

画像とバーコードはブラウザからアップロード・入力できます。データはユーザーのホームディレクトリの `~/.goods_organizer.json` に保存され、アップロード画像は `~/.goods_organizer_images/` に保存されます。バーコード照合時のみインターネット接続が必要です。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。
