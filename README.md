# コレクト | グッズ管理

Flet で作ったブラウザ用のグッズ管理アプリです。

## 主な機能

- 所持グッズを絞り込み、商品名・作品名から Google ショッピングでグッズを検索
- グッズ登録・編集時に端末のフォルダから画像を添付して一緒に保存し、所持画像との完全一致を確認
- 登録したグッズを所持品一覧から確認ダイアログ付きで削除
- 商品ページURLを登録し、所持品や検索結果から商品ページを直接開く
- バーコードを入力して Open Food Facts の公開データで商品を照合
- グッズを選択して登録し、購入済み・購入予定の状態や購入予定日、購入済み個数、購入金額、メモを管理
- 発売日、イベント、受取予定、グッズの購入予定日などのスケジュールを追加・編集・削除
- 近い予定や貯金の進捗、期限を通知パネルで確認できる
- 複数の貯金目標と達成予定日、進捗を追加・編集・削除
- アプリ内の「安心・データ」から、データの保存先や外部サービスへの送信内容を確認できる
- メールアドレスとパスワードでアカウントを作成・ログインし、グッズ・予定・貯金目標をアカウントごとに保存
- リンクを開くと自動でゲスト利用を開始（データはページを開いている間だけ保持し、終了時に破棄）

グッズ登録では商品名・商品ページURL・購入状況・購入金額が必須です。購入済みの場合は購入個数も必須です。画像、作品名・ブランド、バーコード、メモは任意です。

## 使用技術と担当

| 技術・サービス | 関係する部分 |
| --- | --- |
| Python | 商品・予定・貯金目標の管理、検索、データ保存などのアプリ処理 |
| Flet | 画面表示と操作。ブラウザで使う Web アプリとして起動 |
| ブラウザ | 商品情報やバーコードの入力、画像のアップロード、アプリの表示 |
| Google ショッピング | 商品名・作品名からグッズを検索 |
| Open Food Facts API | バーコードから公開商品情報を照合 |
| Google 検索 / Google Lens | 商品名や選択画像を使った外部検索 |
| SQLite・JSON・ローカルファイル | アカウント情報を `~/.goods_organizer_accounts.sqlite3`、各アカウントのデータと画像を `~/.goods_organizer_users/` に保存 |

センサーや IoT 機器、クラウドストレージは使用していません。アカウント利用時の登録データと画像はアプリ実行端末にアカウントごとに保存されます。ゲスト利用時のデータは一時的にメモリと一時領域だけに置かれ、ログアウトまたはページ切断時に破棄されます。パスワードはハッシュ化して保存しますが、登録データ自体は暗号化していません。メールアドレスの確認やパスワード再設定のメールは送信しません。パスワードを忘れるとアカウントを復旧できないため、安全な場所に保管してください。

最初に登録したアカウントには、以前のローカルデータがあれば移行されます。公開リンクを共有する前に、所有者が最初にアカウントを作成してください。バーコード照合では番号を Open Food Facts に送信し、Google ショッピングを開くと検索語が Google に送信されます。個人情報を検索語・メモに入力しないでください。

外部公開する場合は、HTTPS によるポート転送を使用してください。`main.py` はポート `8000` で全ネットワークインターフェースにバインドします。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。

## 公開リンク

現在の Codespaces 環境では、ポート `8000` を公開しています。

https://squalid-troll-jr9vprp9qgwvf5w5w-8000.app.github.dev

Codespaces を停止すると公開リンクは一時的に利用できません。再開した後は次のコマンドでアプリを起動し直してください。

```bash
source .venv/bin/activate
nohup python main.py >/tmp/collect.log 2>&1 &
gh codespace ports visibility 8000:public
```

## 無料ホスティング（Render）

Codespacesを停止してもリンクを維持できるよう、Renderで公開できます。

1. https://dashboard.render.com に GitHubアカウントでログイン
2. **New** → **Blueprint** を選択
3. このリポジトリを接続
4. `render.yaml` を検出してデプロイを実行

無料プランでは一定時間アクセスがないとスリープし、次のアクセス時に起動します。
